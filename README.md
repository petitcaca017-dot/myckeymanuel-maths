# MYCKEYMANUEL — Le DS

Jeu complet jouable dans un navigateur, sans Python ni installation.

## Jouer

Ouvre `index.html` pour lancer la version locale. Sur le site, Entrée démarre l’introduction et permet aussi de la passer. Les réponses se saisissent directement dans la case de dialogue.

Le bouton jaune en haut à droite ouvre Tetris, avec sac de 7 pièces, fantôme, aperçu, réserve, score, niveaux jusqu’à 255 et vitesse croissante.

## Hébergement public

Le site est statique et peut être publié sur GitHub Pages ou tout autre hébergeur de fichiers statiques. Il ne nécessite aucun serveur applicatif.
